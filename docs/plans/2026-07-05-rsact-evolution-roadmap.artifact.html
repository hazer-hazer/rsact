          Cross-cutting invariants every workstream must respect these
          • Render gating I1–I7: identity aliasing impossible by construction; records live and die with their element; nothing consumes a part's dirtiness except executing it; deps re-tracked per run; parent redraw ⇒ child overdraw, child dirty ⇒ page dirty, O(1) idle gate survives; 0 idle allocs; panic-safe observer restore.
          • Crate encapsulation (maintainer, binding): rsact-reactive stays UI-vocabulary-free — no ElId/part/page knowledge in the core; ownership maps for reactive handles live with their owner (rsact-ui), never in a core registry.
          • Layout stop rule: upward propagation stops at a node only if both resolved outer_size and min_size are unchanged under unchanged inputs — min_size feeds parent wrap decisions and min-clamps over max in fluid children.
          • Arena↔layout parallelism is load-bearing (positional zip in event + render passes) until WS5.1 makes identity explicit; divergence must log-degrade, never panic.
          • "UI must never panic": every new path logs and degrades; no new unwrap on render/event/nav paths; prefer exposing try_*/Option to the user (WS1.8).
          • No feature-flag sprawl: sanctioned axes only — storage backend, render backend, math backend (libm | micromath), font provider, extras, diagnostics, test-utils (+ incremental-layout while maturing). Everything else must be pay-per-use by construction.
